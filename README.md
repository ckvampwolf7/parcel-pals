# 택배친구 · Parcel Pals

귀여운 택배친구가 내 택배가 지금 어디쯤인지, 무슨 일이 있었는지 쉬운 말로 알려주는 배송 조회 웹앱(PWA)입니다.

| 친구 | 모습 | 담당 |
|---|---|---|
| **붕붕이** (Vroomy) | 주황색 트럭 | 국내 택배 기본 |
| **슝슝이** (Zoomy) | 파란 비행기 | 해외 택배 기본 |
| **토토** (Toto) | 분홍 토끼 배달원 | 원하면 선택 |

## 주요 기능
- **택배 등록:** 송장번호를 입력하거나 카톡·문자 메시지를 통째로 붙여넣으면 번호를 찾아냅니다. 택배사 후보를 순위대로 보여주고 한 번에 바꿀 수 있습니다. 공유하기(Web Share Target)로도 등록할 수 있습니다.
- **여정 장면:** 친구가 판매자 → 허브 → 공항·세관 → 동네 → 우리 집 경로 위를 실제 진행률만큼 이동합니다.
  - 하늘은 낮·노을·밤으로 바뀝니다.
  - 해외 택배는 통관 후 국내 택배사로 넘어가는 "인계" 장면이 나옵니다.
  - 배송이 완료되면 축하 효과가 나옵니다.
- **쉬운 말 설명:** "간선하차" 같은 택배 용어를 쉬운 문장으로 풀고 다음에 일어날 일을 알려줍니다. 원문도 볼 수 있습니다.
  - FedEx·UPS·DHL 같은 해외 택배사의 실제 기록은 국내 용어(간선·허브) 대신 "페덱스 거점에 도착했어요"처럼 그 택배사 기준으로 설명해요. 대문자 지명(CHICAGO)도 보기 좋게(Chicago) 바꿔요.
- **상황 알림:** 지연, 업데이트가 오래 없음, 편의점 수령 대기 같은 상황을 솔직하게 알려줍니다.
- **자동 갱신:** 새 소식은 읽지 않음 표시, 알림함, 앱 내 토스트, 브라우저 알림으로 알려줍니다. 브라우저 알림은 앱이 백그라운드일 때만, 밤 10시~아침 8시는 쉽니다.
- **기타:** 한국어·영어, 라이트·다크 모드, 움직임 줄이기, 온보딩, 데모 택배, 설치형 PWA(오프라인 동작).

## 실제 배송 조회 (실시간)
- 내가 등록한 택배는 **실제 택배사 정보**를 가져와요. 데이터는 [Delivery Tracker](https://tracker.delivery)에서 받아요.
  - 키 없이 쓰는 **무료 v1 API**를 기본으로 써요. 42개 택배사를 지원하고, 브라우저에서 바로 호출할 수 있어요.
  - **API 키(선택)**를 넣으면 공식 v2 API를 먼저 쓰고, 실패하면 v1으로 넘어가요. 무료 플랜 키는 21일마다 콘솔에서 재발급해야 해요.
  - ⚠️ v1은 공식적으로 지원 종료가 예고된 API예요. 아직 동작하지만 언제든 멈출 수 있어요. 멈추면 설정 → 실시간 조회 → API 키를 넣어 주세요.
- **지원 택배사:** CJ대한통운, 한진, 롯데, 우체국(국내·EMS), 로젠, 쿠팡, 경동, 대신, GS편의점, 차이냐오, 만국우편(S10 번호), UPS, FedEx, DHL, USPS.
  - YunExpress, 4PX, SF, Amazon은 실시간 조회가 안 돼요. 택배사 사이트 링크로 안내해요.
- **조회 주기:** 앱이 열려 있는 동안 기본 10분마다 자동으로 확인해요(5·10·30분 중 선택). 새로고침 버튼은 30초에 한 번씩 쓸 수 있어요. 배송 완료 후 하루가 지난 택배는 더 조회하지 않아요.
- **택배사에 아직 기록이 없을 때** (송장 등록 직후): 이유를 설명하고, 다른 택배사 후보로 바로 다시 조회할 수 있어요.
- **연결 확인:** 설정 → 실시간 조회 → "연결 테스트" 또는 "테스트 택배로 확인하기"를 누르면 돼요. 테스트 택배는 tracker.delivery의 테스트 운송장이에요.
- **데모 택배:** 온보딩·설정에서 추가하는 데모 택배는 시뮬레이션이에요. 시간 빨리 감기(⏩)는 데모 택배에만 있어요.
- 개인정보: 택배 정보는 내 기기(localStorage)에만 저장돼요. 조회할 때만 tracker.delivery로 택배사 ID와 운송장 번호를 보내요.

## 배포 (GitHub Pages)
`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 타입 검사, 단위 테스트, 빌드를 거쳐 Pages에 자동 배포해요.
처음 한 번만 저장소의 **Settings → Pages → Source를 "GitHub Actions"**로 바꿔 주세요. 주소는 `https://<사용자>.github.io/<저장소>/`예요.
상대 경로로 빌드(`base: './'`)해서 하위 경로에서도 그대로 동작해요.

## 실행
```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # dist/ (서비스워커 프리캐시 포함). 아무 정적 호스팅에 올리면 PWA로 설치 가능
npm run preview    # 빌드 결과 확인
```

## 품질 확인
```bash
npm run typecheck  # TypeScript strict
npm test           # 단위 테스트 (Vitest, 202개)
npm run e2e        # E2E + 접근성(axe) + 오프라인 + 실시간 조회 테스트 (Playwright, 모바일·데스크톱 128개)
```

## 구조
```
src/types.ts      공통 도메인 계약
src/engine/       택배사 인식, 붙여넣기 추출, 실시간 조회(live/), 시뮬레이션, 캐릭터 대사, 날짜 포맷
src/store/        상태, 저장(localStorage), 자동 갱신, 알림 이벤트
src/characters/   붕붕이·슝슝이·토토 SVG (7가지 기분), 친구 선택기
src/components/   디자인 시스템, 탭바, 토스트
src/screens/      홈, 등록, 알림함, 설정, 온보딩
src/journey/      상세 화면 (여정 장면, 타임라인, 메뉴)
src/pwa/          서비스워커 등록, 브라우저 알림, 설치 안내
docs/             계획(PLAN), 팀 브리프, 경쟁사 조사, 엔진·캐릭터·QA 문서
```

## 만든 과정
리드가 계획, 경쟁사 조사, 공통 계약과 스텁을 만들었습니다. 이후 캐릭터·엔진·UI·여정·PWA/QA 5개 팀이 병렬로 개발했고, 리드가 검토와 병합, 통합 테스트, 수정을 맡았습니다. 자세한 내용은 `docs/PLAN.md`와 `docs/TEAM_BRIEF.md`에 있습니다.
