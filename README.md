# 택배친구 · Parcel Pals

귀여운 택배친구가 내 택배가 지금 어디쯤인지, 무슨 일이 있었는지 쉬운 말로 알려주는 배송 조회 웹앱(PWA)입니다.

| 친구 | 모습 | 담당 |
|---|---|---|
| **붕붕이** (Vroomy) | 주황색 트럭 | 국내 택배 기본 |
| **슝슝이** (Zoomy) | 파란 비행기 | 해외 택배 기본 |
| **토토** (Toto) | 분홍 토끼 배달원 | 원하면 선택 |

## 주요 기능
- **택배 등록:** 송장번호를 입력하거나 카톡·문자 메시지를 통째로 붙여넣으면 번호를 찾아냅니다. 택배사 후보를 순위대로 보여주고 한 번에 바꿀 수 있습니다. 공유하기(Web Share Target)로도 등록할 수 있습니다.
- **여정 장면:** 친구가 판매자 → 허브 → 공항·세관 → 동네 → 우리 집 경로 위를 실제 진행률만큼 이동합니다.
  - 하늘은 낮·노을·밤으로 바뀝니다.
  - 해외 택배는 통관 후 국내 택배사로 넘어가는 "인계" 장면이 나옵니다.
  - 배송이 완료되면 축하 효과가 나옵니다.
- **쉬운 말 설명:** "간선하차" 같은 택배 용어를 쉬운 문장으로 풀고 다음에 일어날 일을 알려줍니다. 원문도 볼 수 있습니다.
- **상황 알림:** 지연, 업데이트가 오래 없음, 편의점 수령 대기 같은 상황을 솔직하게 알려줍니다.
- **자동 갱신:** 새 소식은 읽지 않음 표시, 알림함, 앱 내 토스트, 브라우저 알림으로 알려줍니다. 브라우저 알림은 앱이 백그라운드일 때만, 밤 10시~아침 8시는 쉽니다.
- **기타:** 한국어·영어, 라이트·다크 모드, 움직임 줄이기, 온보딩, 데모 택배, 설치형 PWA(오프라인 동작).

> **이번 버전의 배송 데이터는 시뮬레이션입니다.** 실제 택배사 API 대신 송장번호마다 정해진 그럴듯한 여정을 만들어 보여줍니다. 실제 API(Delivery Tracker 등)를 붙일 수 있는 구조는 `src/engine/providers/`에 있습니다(docs/engine.md 참고). 설정에서 시뮬레이션 속도(기본 60배)를 바꿀 수 있고, 상세 화면의 "⏩ +3시간" 버튼으로 시간을 빨리 감을 수 있습니다.

## 실행
```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # dist/ (서비스워커 프리캐시 포함). 아무 정적 호스팅에 올리면 PWA로 설치 가능
npm run preview    # 빌드 결과 확인
```

## 품질 확인
```bash
npm run typecheck  # TypeScript strict
npm test           # 단위 테스트 (Vitest, 177개)
npm run e2e        # E2E + 접근성(axe) + 오프라인 테스트 (Playwright, 모바일·데스크톱 114개)
```

## 구조
```
src/types.ts      공통 도메인 계약
src/engine/       택배사 인식, 붙여넣기 추출, 시뮬레이션, 캐릭터 대사, 날짜 포맷
src/store/        상태, 저장(localStorage), 자동 갱신, 알림 이벤트
src/characters/   붕붕이·슝슝이·토토 SVG (7가지 기분), 친구 선택기
src/components/   디자인 시스템, 탭바, 토스트
src/screens/      홈, 등록, 알림함, 설정, 온보딩
src/journey/      상세 화면 (여정 장면, 타임라인, 메뉴)
src/pwa/          서비스워커 등록, 브라우저 알림, 설치 안내
docs/             계획(PLAN), 팀 브리프, 경쟁사 조사, 엔진·캐릭터·QA 문서
```

## 만든 과정
리드가 계획, 경쟁사 조사, 공통 계약과 스텁을 만들었습니다. 이후 캐릭터·엔진·UI·여정·PWA/QA 5개 팀이 병렬로 개발했고, 리드가 검토와 병합, 통합 테스트, 수정을 맡았습니다. 자세한 내용은 `docs/PLAN.md`와 `docs/TEAM_BRIEF.md`에 있습니다.
